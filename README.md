Este projeto foi desenvolvido utilizando o Bolt, um editor de código online similar ao VS Code, mas que opera diretamente no navegador.

Escolhi o Bolt devido a algumas vantagens como

Integração com GitHub oque facilita enviar e sincronizar com repositórios

Conexão com Figma (diretamente com a conta do Figma)

Aba que divide o código da visualização da página web

Commits:
O projeto foi desenvolvido em uma única sessão no Bolt, (por isso a falta de commits) estruturei o desenvolvimento em etapas equivalentes a commits:

1. Background / Footer
Cores definidas: Amarelo (#e6e900) e Vermelho (#d01313)

Design base estabelecido

Estrutura HTML inicial criada (substituindo página branca com "hello world")

2. Layout e Posicionamento
Divisão entre texto e imagem implementada

Textos placeholder e imagens temporárias posicionadas

Seguindo o modelo do Figma

3. Conteúdo e Estilo
Imagens e textos definitivos aplicados

Estilo Brutalismo Web com adaptações para não ficar muito "Progressista"

4. Componentes de Cards
Integração de texto e imagens mostrando localização e descrição

5. Elementos Interativos
Botões configurados com efeitos de inversão de cores

Link de email funcional (redireciona para caixa de envio)

6. Refinamento 
Ajustes de altura, largura e proporções

Polimento geral dos elementos visuais
